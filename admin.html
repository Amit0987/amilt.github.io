Connect your website

Enter your website address and a GitHub access token once. After that, every add, edit and delete is saved to your website automatically.

How do I get a GitHub token?

On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Select only your website repository and set Contents permissions to Read and write. Paste the generated token above.
